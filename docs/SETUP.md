# ConstructGuard AI — How to Run It

## What You Need Before Starting

1. Node.js 20+ (download: https://nodejs.org)
2. An Anthropic API key (https://console.anthropic.com) — needed for Action Agent
3. A Gemma provider key (see GEMMA4_SETUP.md for options)

---

## Step 1 — Set Up Your API Keys

```bash
cd backend
cp .env.example .env
# Now edit .env with your actual keys
```

Minimum to get started:
```
ANTHROPIC_API_KEY=sk-ant-your-key
GEMMA_PROVIDER=google
GOOGLE_AI_API_KEY=AIzaSy-your-key
```

---

## Step 2 — Install and Run the Backend

```bash
cd backend
npm install
npm run dev
# Server starts on http://localhost:3001
```

You should see:
```
🏗  ConstructGuard AI Server running on http://localhost:3001
📡 Gemma Provider: google
🤖 Anthropic key:  ✓ set
🌍 Google AI key:  ✓ set
```

---

## Step 3 — Run the Frontend

The frontend from the Claude artifact can be saved as an HTML file and opened directly, OR:

```bash
cd frontend
npm create vite@latest . -- --template react
npm install
npm run dev
# Opens on http://localhost:5173
```

---

## Step 4 — Test the Analysis Pipeline

```bash
# Download a test construction image
curl -o test.jpg "https://upload.wikimedia.org/wikipedia/commons/thumb/a/a7/Camponotus_flavomarginatus_ant.jpg/320px-Camponotus_flavomarginatus_ant.jpg"

# Test the API
curl -X POST http://localhost:3001/api/analyze \
  -F "image=@test.jpg" \
  -F "siteId=site-a" \
  | python3 -m json.tool
```

## Deployment (When Ready)

### Backend → Railway.app
```bash
# Install Railway CLI
npm install -g @railway/cli
railway login
railway init
railway up
# Add your env vars in Railway dashboard
```

### Frontend → Vercel
```bash
npm install -g vercel
vercel
# Set VITE_BACKEND_URL=https://your-railway-url.railway.app
```
